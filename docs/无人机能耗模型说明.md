# 无人机运输能耗模型说明

## 1. 模型来源与说明

本题附录 2 已明确规定运输无人机的能耗由两部分组成：

\[
E_{gij}(q)=E_{gij}^{\mathrm{hor}}(q)+E_{gij}^{\mathrm{up}}(q)
\]

其中：

- \(E_{gij}^{\mathrm{hor}}(q)\)：水平巡航能耗；
- \(E_{gij}^{\mathrm{up}}(q)\)：爬升附加能耗；
- 下降附加能耗效率取 0，即不单独计算下降附加能耗。

题目还规定，每个运输架次必须满足返航安全余量约束。

需要特别说明的是：

> 水平能耗公式并未在题面中直接完整给出，因此本文采用“基于标准航程标定的等效单位距离能耗模型”。该模型具有文献依据，但并非唯一真实物理能耗模型，论文中应明确说明建模假设、单位以及敏感性分析。

---

## 2. 载荷—等效航程模型

题目给出了机型 \(g\) 在当前有效载荷 \(q\) 下的等效航程关系：

\[
\boxed{
L_g(q)
=
L_g^0-
\left(L_g^0-L_g^F\right)
\left(\frac{q}{Q_g}\right)^{3/2}
}
\]

其中：

- \(L_g(q)\)：载荷为 \(q\) 时的等效航程；
- \(L_g^0\)：空载标准航程；
- \(L_g^F\)：满载标准航程；
- \(Q_g\)：最大载货质量；
- \(q\)：当前有效载荷，满足 \(0\le q\le Q_g\)。

该公式反映：随着载荷增加，无人机的等效航程逐渐下降，并采用 \(3/2\) 次方描述载荷对能耗的非线性影响。

---

## 3. 等效水平单位距离能耗模型

设机型 \(g\) 单组电池的可用能量为

\[
E_g^{\mathrm{use}}
\]

则可定义载荷 \(q\) 下的等效水平单位距离能耗率：

\[
\boxed{
\varepsilon_g(q)
=
\frac{E_g^{\mathrm{use}}}{L_g(q)}
}
\]

单位为：

\[
\mathrm{kWh/m}
\]

若航段 \(i\rightarrow j\) 的水平飞行距离为 \(d_{ij}\)，则水平巡航能耗为：

\[
\boxed{
E_{gij}^{\mathrm{hor}}(q)
=
\varepsilon_g(q)d_{ij}
=
\frac{E_g^{\mathrm{use}}d_{ij}}{L_g(q)}
}
\]

代入等效航程公式：

\[
\boxed{
E_{gij}^{\mathrm{hor}}(q)
=
\frac{
E_g^{\mathrm{use}}d_{ij}
}{
L_g^0-
\left(L_g^0-L_g^F\right)
\left(\frac{q}{Q_g}\right)^{3/2}
}
}
\]

这正对应程序中“可用能量 / 标准航程”作为基础单位距离能耗，再根据载荷对应的有效航程进行修正的思路。

---

## 4. 总航段能耗模型

按照题目附录 2，单个航段总运输能耗为：

\[
\boxed{
E_{gij}(q)
=
E_{gij}^{\mathrm{hor}}(q)
+
E_{gij}^{\mathrm{up}}(q)
}
\]

其中：

- 水平巡航能耗由等效航程模型计算；
- 爬升附加能耗根据爬升高度、无人机质量及题目统一规则计算；
- 下降过程不单独计入附加能耗。

---

## 5. 架次返航安全约束

对于一个完整运输架次 \(p\)，设各航段当前剩余载荷为 \(q_{pij}\)，则总能耗为：

\[
E_p
=
\sum_{(i,j)\in p}
E_{gij}(q_{pij})
\]

若机型 \(g\) 的返航安全余量比例为 \(\rho_g\)，则应满足：

\[
\boxed{
\sum_{(i,j)\in p}
E_{gij}(q_{pij})
\le
(1-\rho_g)E_g^{\mathrm{use}}
}
\]

该约束直接用于判断：

- 某一载荷是否能够安全往返；
- 最大安全载荷；
- 某批货箱是否能够合并运输；
- 某条多点路径是否满足能源安全要求。

## 6. 文献中的物理依据

### 6.1 Dorling 等：功率与总质量的 \(3/2\) 次方关系

参考文献：

> Dorling K, Heinrichs J, Messier G G, et al.  
> *Vehicle Routing Problems for Drone Delivery*.  
> IEEE Transactions on Systems, Man, and Cybernetics: Systems, 2017, 47(1): 70–85.

多旋翼无人机悬停功率可写为：

\[
P^*
=
\frac{T^{3/2}}
{\sqrt{2\rho A}}
\]

无人机总质量记为：

\[
M=W+m
\]

则：

\[
T=Mg
\]

对于 \(n\) 个旋翼的无人机，可得到近似功率模型：

\[
\boxed{
P(m)
=
(W+m)^{3/2}
\sqrt{
\frac{g^3}{2\rho A n}
}
}
\]

因此：

\[
\boxed{
P\propto M^{3/2}
}
\]

这为题目中载荷影响采用 \(3/2\) 次方形式提供了物理背景。

公开下载：

- arXiv PDF：<https://arxiv.org/pdf/1608.02305>
- DOI：<https://doi.org/10.1109/TSMC.2016.2582745>

### 6.2 Zhang 等：单位距离能耗模型

参考文献：

> Zhang J, Campbell J F, Sweeney D C, et al.  
> *Energy Consumption Models for Delivery Drones: A Comparison and Assessment*.  
> Transportation Research Part D: Transport and Environment, 2021, 90: 102668.

该文将无人机能耗统一表示为单位距离能耗：

\[
Epm=\text{Energy per meter}
\]

一种典型形式为：

\[
\boxed{
Epm(q)
=
\frac{
\left(M(q)g\right)^{3/2}
}{
\eta v\sqrt{2n\rho A}
}
}
\]

其中：

- \(M(q)\)：机体、电池和载荷的总质量；
- \(v\)：巡航速度；
- \(n\)：旋翼数量；
- \(\rho\)：空气密度；
- \(A\)：单旋翼桨盘面积；
- \(\eta\)：动力系统效率。

因此，飞行距离 \(d\) 的水平能耗可表示为：

\[
\boxed{
E^{\mathrm{hor}}(q,d)=Epm(q)\,d
}
\]

这与本文“先构造单位距离能耗率，再乘以飞行距离”的建模结构一致。

论文页面：

- ResearchGate：<https://www.researchgate.net/publication/341945067_Energy_Consumption_Models_for_Delivery_Drones_A_Comparison_and_Assessment>
- ScienceDirect：<https://www.sciencedirect.com/science/article/pii/S1361920920308531>
- DOI：<https://doi.org/10.1016/j.trd.2020.102668>

## 7. 与当前程序 `solver.py` 的对应关系

当前程序采用的基本思路是：

\[
e_0
=
\frac{E_g^{\mathrm{use}}}{L_g^0}
\]

即先以“可用能量 / 空载标准航程”定义空载单位距离能耗。

再根据载荷对应的等效航程进行比例修正：

\[
e(q)
=
e_0\frac{L_g^0}{L_g(q)}
\]

整理得到：

\[
\boxed{
e(q)
=
\frac{E_g^{\mathrm{use}}}{L_g(q)}
}
\]

因此，程序最终采用的水平能耗模型可写成：

\[
\boxed{
E_{gij}^{\mathrm{hor}}(q)
=
\frac{E_g^{\mathrm{use}}}{L_g(q)}d_{ij}
}
\]

从数学上看，该表达式与前述“基于标准航程标定的等效单位距离能耗模型”完全一致。

## 9. 建模结论

原先“能耗模型完全自行假设”的说法不够准确。

更严谨的结论应为：

> **题目已经给出了载荷—等效航程的核心关系，而水平单位距离能耗采用了基于电池可用能量与等效航程的标定方法。该方法具有 Dorling、Zhang 等无人机能耗文献的理论依据，但具体的 \(E^{\mathrm{hor}}=E^{\mathrm{use}}d/L(q)\) 仍属于本文的等效建模假设，而非唯一真实物理规律。**

因此，在论文中必须明确：

1. 模型假设；
2. 变量与单位；
3. 载荷—航程关系；
4. 水平能耗标定方法；
5. 爬升附加能耗；
6. 返航安全余量；
7. 能耗参数敏感性分析。

这样得到的“最大安全载荷”和“最优组批方案”才具有完整的建模依据和可解释性。
