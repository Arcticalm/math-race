# 第一问：单点往返运输能力与货箱组批方案

## 1. 任务边界与题意

第一问只研究从临时调度中心 O01 到单个服务区 S_i 再返回 O01 的直接往返架次。一次架次只服务一个服务区；同一服务区允许分多架次交付；货箱不得跨服务区组批。题目明确不考虑实体运输无人机和共享电池的跨架次调度，因此第一问是单架次可行性与逐服务区组批优化，不是问题二的车辆/电池排程。

需要完成三项工作：

1. 对 15 个服务区、3 种运输机型分别计算最大安全载荷，形成 15×3 矩阵。
2. 货箱不可拆分且每箱恰好安排一次；满足载质量、装载体积、航程/能量和返航安全余量约束，确定各服务区的分批组批方案。
3. 在全部货箱交付的前提下，综合往返架次数、总运输能耗、累计作业时间优化方案，并解释指标权衡；再改变返航安全余量，分析安全载荷及组批结果变化。

### 已观察到的数据规模

- 场景有 1 个 O01、15 个服务区、80 个逐箱记录；服务区之间独立求解。
- 运输机型 A/B/C 的最大货载分别为 25/30/80 kg，可用装载体积分别为 0.060/0.073/0.250 m³；能量与航程参数需以工作簿原值为准。
- 仓库确实包含 30 m DEM GeoTIFF 和 MAT 栅格，故不应沿用参考 PDF 当时“未见可计算 DEM”的缺口判断。仍需程序读取后验证 CRS、覆盖范围和 NoData。
- 第一问按题意不分配 U01–U08，也不限制每种机型可用架次数；机型数量只在后续问题的资源调度中约束。

## 3. 目标与约束的数学表达

令 i 表示服务区，g 表示机型，b 表示货箱，r 表示候选架次（机型 + 该服务区的一个货箱子集）。路线固定为 O01→S_i→O01。

### 3.1 最大安全载荷

对路线 i、机型 g、候选载荷 q，按题目/附件规定的航段能耗模型和 DEM 地形剖面计算完整往返能耗 E_ig(q)。安全可用能量记为 E^safe_g。定义：

`Qsafe_ig = max { q : 0 ≤ q ≤ Qrated_g, E_ig(q) ≤ E^safe_g }`

并同时满足去程载荷对应的标准航程、返程空载标准航程等模型安全条件。`Qsafe_ig` 是连续载荷上限；离散货箱组批还须分别检查质量、体积和实际能耗，不能只用总质量上限判可行。

如果能耗关于载荷单调不减，可对 q 二分搜索；每次能耗计算必须按去程承载 q、送达后返程空载（或题目指定的返程状态）分别回放。若附件公式不能推出单调性，先数值验证再选择搜索法。

### 3.2 组批集合划分

对每个服务区独立建立候选架次集合 R_i。候选 r 包含机型 g(r) 和箱集 B_r⊆B_i。仅当以下条件全部满足时保留：

- 每箱不可拆，候选箱均属于同一服务区；
- `Σ_{b∈B_r} mass_b ≤ Qrated_g` 且不超过本路线的安全载荷；
- `Σ_{b∈B_r} volume_b ≤ V_g`；
- 依照实际载荷、DEM 航段和安全余量计算的往返能耗不超过可用能量，且满足航程/返航条件。

令 x_r∈{0,1} 表示是否执行候选架次 r。每个箱恰好覆盖一次：

`Σ_{r∈R_i: b∈B_r} x_r = 1    ∀ i, b∈B_i`

将 15 个服务区分别求解后合并。某服务区最多 15 箱，直接枚举其子集规模最多 2^15=32768；可用按服务区独立的精确集合划分/整数规划，不需要先上遗传算法。

### 3.3 多指标目标及建议优先级

题面要求综合考虑三项，但未规定权重或优先顺序。为避免任意加权掩盖取舍，建议主结果采用字典序：

1. 最小化总往返架次数 `N=Σ_r x_r`；
2. 在最少架次方案中最小化总往返运输能耗 `E=Σ_r E_r x_r`；
3. 在前两项最优解中最小化累计作业时间 `T=Σ_r T_r x_r`。

另补充 Pareto/权重方案作为权衡说明，而不是声称字典序是题目唯一指定。对时间要给出明确定义：推荐先报告“各架次准备、装载、飞行及点位交接时间之和”；若题目意图是墙钟完工时间，单服务区多架次并行/机队数量限制在第一问中并未定义，应另列口径，不能把问题二资源约束偷偷并入。

## 4. 求解流程

1. **读数审计**：读取各工作簿指定区域、逐箱数据、坐标和 DEM 元信息；确认 80 箱唯一、服务区映射完整，记录 CRS/单位/NoData。
2. **地形路线计算**：将 O01 与服务区坐标投影到 DEM CRS；沿两端点地面直线路径按不粗于 DEM 网格的间距采样高程，构造去程/返程剖面。区分水平距离与三维航迹距离，并按统一规则处理端点海拔与栅格高程不一致。
3. **单架次物理内核**：实现每种机型、路线、载荷下的飞行时间、能耗、返航余量与可行性计算；先用空载、额定载荷和手算路线做单元级 sanity check。
4. **安全载荷矩阵**：对 15×3 个组合求 `Qsafe_ig`，同时保存限制因素（额定载重、能量、航程或其他约束）。
5. **候选架次生成**：按服务区枚举货箱子集和机型；利用质量/体积等廉价条件剪枝，再运行精确能耗/返航判定。
6. **精确组批优化**：对每个服务区解集合划分；通过最少架次下界、覆盖校验和小实例穷举验证求解器结果。
7. **敏感性分析**：在统一安全余量定义下扫描 ρ（至少包含基准与较松/较严值；可参考 10%、15%、20%、25%、30%），重算安全载荷与组批；记录架次增加、机型切换和箱组跳变的阈值。
8. **结果复核与导出**：检查每箱恰好出现一次、不得跨区、各架次质量/体积/能量安全可行；生成结果表和可读图形。

## 5. 预期产出

1. **最大安全载荷表**：15 行服务区 × A/B/C 三列，单位 kg；建议另列往返距离、最高/平均地形高程、可用能量、临界载荷能耗及约束类型，便于解释地形和距离影响。
2. **架次组批明细表**：每行一个架次，含服务区、架次编号、机型、箱号列表、总质量、总体积、去/返程能耗、往返飞行时间、准备/装载/交接时间、能量余量与可行状态。
3. **服务区汇总表**：每区箱数、架次数、总能耗、累计作业时间、机型使用数及未交付箱数（最优完整覆盖时应为 0）。
4. **全局指标及权衡说明**：总架次、总能耗、累计作业时间；若生成 Pareto 解，提供非支配解和指标取舍说明。
5. **余量敏感性表/图**：不同 ρ 下 15×3 安全载荷、总架次数、总能耗、累计时间；标注组批结构跳变点。
6. **空间/解释图**：服务区往返距离或地形剖面图、安全载荷热图；图中明确单位、坐标/高程处理和安全余量口径。
7. **可复核材料**：数据清洗审计摘要、参数和假设表、求解器状态/最优性信息、覆盖与可行性校验结果。

## 6. 当前必须确认/不可臆造的事项

- 题目文件说“返航安全能量余量”，参数表提供的是“返航电量下限（%）”。需检查附件其他说明/能耗规则，确定它代表最低剩余 SOC、总能量预留比例，还是两者等价；参考 PDF 的 `(1−ρ)E_use` 只是建模建议，不是自动生效的题面定义。
- 运输机参数表给出空载/满载标准航程与能量；题面虽给出载荷对标准航程的公式和能耗组成，但没有给出水平能耗的显式计算式，且爬升效率量纲需按参数说明确认。数值实现必须把采用的水平能耗校准和效率解释作为显式模型假设，不得当作题目事实。
- 坐标经纬度和 DEM 栅格必须在正确 CRS 下采样。若航线直线穿出有效 DEM 范围、遇 NoData 或 O01/服务区点海拔与 DEM 不一致，应记录处理规则并报告影响。
- “累计作业时间”具体是否含装载、交接和固定准备时间，要依据题目定义；若题面未定义，采用明确口径并同时提供分项时间。
- 返航能量校核按返程空载计算是自然的物理解释，但仍应和题目规则一致；若有投放装置/回程附加载荷，须纳入。
- 第一问要求的是方案与权衡，不等同于单一加权和。若同时给加权结果，公开权重、单位归一化方式和 Pareto 对照。
