# 第二问解法 solve2

从仓库根目录运行：

```bash
python3 -m src.promble2.solve2.solver
```

所需依赖与 `src/problem2/requirements.txt` 相同。本解法复用 `src/problem2/solver.py` 的航段物理模型、资源调度器及独立重放审计。先完整枚举每个服务区的可行货箱子集，分别按“架次数→能耗→作业时间”“作业时间→架次数→能耗”“能耗→架次数→作业时间”作逐区精确集合划分；同时保留原构造式组批。再对每个组批方案尝试两区合并、四种发车顺序和两种局部机型/资源指派策略，仅保留通过完整审计的调度。

主方案按全部期望时间的加权迟到量、完成时间、能耗、架次数依次比较。结果输出到 `outputs/promble2/solve2/`，包括模板工作簿、逐箱/逐架次/电池审计表、路线图、资源甘特图、送达图和候选权衡图。`candidate_comparison.csv` 给出全部可行候选的指标；“候选中非支配”仅在这些方案之间成立。

逐区集合划分对其单服务区子问题是精确的。多点合并和共享资源排程仍采用启发式，**不保证第二问全局最优**。水平能耗公式继承第一问的标准航程标定假设，详见 `src/problem2/README.md`。`validation.json` 记录可行性审计与求解范围。
