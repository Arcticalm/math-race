# 问题四：冻结联合排程后的任务分区

`solver.py` 读取第三问结果，保持架次任务、组批、访问顺序、时刻和通信保障关系不变，求 K=2 和 K=3 时各组独立执行的最小资源配置。入口要求 `screening.json` 中具有 `exact_dem_interval_v2` 连续通信认证；旧采样认证须先重新审计。

```bash
.venv/bin/python -m final_code.problem4.solver \
  --input outputs/q3 --output outputs/q4
```

1. 将同运输架次和同中继保障任务关联的服务区取传递闭包，作为不可拆分原子单元。每个第三问架次恰好归属于一个组；禁止跨组复制、拆分、重定时或共享中继任务。
2. 枚举原子单元的全部非空无标签分区，不设默认候选上限，并缓存组统计。若有 13 个原子单元，K=3 有 S(13,3)=261,625 个候选；当前选中方案为 5 个单元，K=2/3 分别 15/25 个。每组每类资源的最小配置等于固定占用区间的重叠峰值。
3. 运输机体占用至返航，电池占用至两阶段充电完成；中继机体还计入周转时间，能源组件占用至充满。区间为左闭右开。同类资源可在组内重新编号，每组持有自己的资源，禁止跨组复用。
4. 按总库存缺口、总资源件数、四项工作量最大变异系数依次选择。四项为运输飞行时间、中继服务时间、运输架次数、箱数。不同资源的件数采用等权相加，这是明确的评价选择，不代表采购费用。
5. 比较按资源类型分别报告组需求、需求之和、未分区全局峰值、分区增加量、总库存缺口或余量。总库存只有一份，不重复作为每个组的库存。另报告质量、箱数、能耗、作业时间的组间统计；质量由第三问逐箱交付表逐项汇总。

输出 `problem4_submission.xlsx`、分区配置、库存与工作量比较、任务和资源区间映射，以及冻结输入的 SHA256。`feasible` 表示存在合法分区，`inventory_feasible` 单独表示现有库存是否足够。完整枚举只证明**固定第三问排程、严格冻结关系、既定评价目标下**的分区最优，不证明前三问或四问联动的全局最优。

验证命令：`.venv/bin/python -m unittest tests.test_audit_q4 -v`。

最终模板表和图分别位于本问结果目录的 `tables/`、`figures/`。总表与程序包由 `python -m final_code.publish` 统一生成。
